# TP Integrador - Gestión de Restaurante - Introducción a las Bases de Datos

Trabajo práctico grupal de la materia Introducción a las Bases de Datos.

## Integrantes

* Morana, Juan Ignacio
* David Paulo Ibañez

## Descripción

Proyecto desarrollado en SQL utilizando MySQL Workbench para la gestión automatizada de pedidos, mesas y mozos.

El trabajo busca aplicar:
* Modelado Conceptual y Lógico (DER)
* Normalización hasta 3FN
* Consultas avanzadas con Joins y Agrupaciones (GROUP BY)

## Tecnologías utilizadas

* SQL
* MySQL Workbench
